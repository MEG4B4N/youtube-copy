# Обновление интерфейса StreamHub

## Главная страница
- Убран приветственный блок «Открой для себя новое»; лента начинается с горизонтальной строки категорий и переключателя сортировки.
- Добавлена левая навигация с SVG-иконками: главная, тренды, подписки, история, плейлисты, «Смотреть позже», понравившиеся, ваши видео, загрузки и канал пользователя.
- Карточки получили быстрые действия для сохранения ролика в «Смотреть позже» и повторной загрузки.
- Добавлены адаптивные состояния панели навигации, карточек и фильтров; учтены клавиатурный фокус и `prefers-reduced-motion`.

## Библиотека пользователя
- История просмотров, «Смотреть позже» и список запущенных загрузок хранятся в `localStorage` текущего браузера. Эти данные не синхронизируются между устройствами.
- Понравившиеся, собственные опубликованные видео, плейлисты и лента подписок загружаются через защищённые API-маршруты.
- На странице плейлистов можно создавать открытые и приватные подборки.
- Скачивание выполняется через API-поток с проверкой видимости видео; браузеру передаётся `Content-Disposition: attachment`.

## Демоданные
- Добавлены демонстрационные темы: нейросети, биолюминесценция океана, северное сияние, вулканы, Солнечная система и история изобретений.
- Превью генерируются локально на Pillow; короткие MP4 создаются FFmpeg. Внешние медиа-ссылки не требуются.
- Seed теперь добавляет только отсутствующие записи по названию и работает также с уже существующей базой.

## Оптимизация
- Для сериализации списков видео агрегаты лайков и комментариев, а также состояние подписки/лайка рассчитываются пакетно, а не отдельными запросами на каждую карточку.
- Слушатели общих кликов навешиваются один раз через делегирование событий, чтобы не плодить обработчики после навигации.
- Изображения карточек загружаются лениво и декодируются асинхронно.
